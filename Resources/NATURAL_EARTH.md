# Natural Earth map data

`world-outline.json` is derived from Natural Earth's 1:110m land polygons. The dataset is public domain. The source ZIP used to produce it is `ne_110m_land.zip`; the conversion script is `Scripts/convert_ne_land.py`.

The source data is available from [Natural Earth 1:110m Physical Vectors](https://www.naturalearthdata.com/downloads/110m-physical-vectors/) under [Natural Earth's terms of use](https://www.naturalearthdata.com/about/terms-of-use/).
